# Understories Tutorials

Tutorials and learning materials for building on Arkiv.

## Contents

### [serverless-dapp101](./serverless-dapp101/)

A 1-hour hands-on workshop to build your first decentralized app with Arkiv.

**What you'll learn:**
- Data sovereignty & decentralized databases
- Building full-stack web3 applications
- Using Arkiv to replace traditional app servers
- Deploying a simple micro-app on Arkiv

**Outcome:** Each participant deploys a simple micro-app that passes the "walkaway test" - data persists independently, no central database required.

### [extractions](./extractions/)

Reference materials extracted from Arkiv ecosystem projects:

- **arkiv-nextjs-starter** - Next.js starter template for Arkiv applications
- **arkiv-app-kit** - TypeScript utilities for building Arkiv apps
- **arkiv-ai-agent-kit** - AI agent prompts and patterns for Arkiv development

## Getting Started

Each tutorial has its own README with setup instructions. Start with [serverless-dapp101](./serverless-dapp101/) for a complete walkthrough.
